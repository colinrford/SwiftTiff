# SwiftTiff

This is a Swift translation of [NGA's `tiff-ios` package](https://github.com/ngageoint/tiff-ios).

I will elaborate here when a little more is fleshed out. For now, though, you can checkout [my fork of `ioridev`'s LiDAR-Depth-Map-Capture-for-iOS](https://github.com/colinrford/LiDAR-Depth-Map-Capture-for-iOS), which swaps the usage of `tiff-ios` for `SwiftTiff`.
